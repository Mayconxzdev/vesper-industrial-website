# Nota de publicação do portfólio

Esta é uma cópia independente do projeto, criada exclusivamente para demonstrar o trabalho de Maycon Ferreira em portfólio técnico e visual.

## Mantido

- Código de interface React.
- Conteúdo e mídia já públicos no site institucional.
- Capturas reais do site em produção.
- Arquitetura de componentes, dados e tradução necessária para executar a interface.

## Removido ou neutralizado

- Configuração de infraestrutura local e de rede.
- Scripts de FTP/publicação operacional.
- API de e-mail, biblioteca de transporte e arquivos de configuração associados.
- Qualquer comportamento desta cópia que poderia encaminhar mensagens para a empresa.

O formulário foi convertido em demonstração visual local. Para falar com a empresa, use exclusivamente o site de produção.

## Direitos e escopo

Este repositório não concede licença de uso das marcas, logotipos, textos institucionais, imagens ou catálogo comercial da Vesper. Ele existe como evidência de uma entrega de design e front-end, não como um template genérico para redistribuição.
