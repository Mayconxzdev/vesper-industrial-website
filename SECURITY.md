# Segurança

## Escopo público

Esta versão não contém credenciais, arquivos de ambiente, integração de e-mail, configuração de FTP ou detalhes de infraestrutura operacional. Esses itens são ignorados pelo Git e não fazem parte do fluxo de execução local.

## Relato responsável

Caso identifique um problema nesta cópia de portfólio, abra uma issue sem publicar dados sensíveis. Para vulnerabilidades relacionadas ao site de produção, utilize os canais oficiais da Vesper, e não este repositório.

## Não inclua

- Senhas, tokens, cookies ou chaves privadas.
- Dados de clientes, leads ou conversas comerciais.
- Endereços internos, configuração de hospedagem ou backups.
